# Portfolio

Statische Website (HTML/CSS). Lokal öffnen: `index.html` im Browser.

## Hosting mit eigener Domain
1. GitHub Pages (Settings → Pages → Branch `main`) oder Netlify/Cloudflare Pages verbinden.
2. Domain im Hosting eintragen, beim Registrar DNS (CNAME/A) setzen.
3. Für GitHub Pages: Datei `CNAME` mit der Domain anlegen.
